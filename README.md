# Isles+
Isles+ is a quality-of-life mod for Skyblock Isles built to make routine gameplay smoother, clearer, and less repetitive with practical in-game helpers and utility features.

[Trailer](https://youtu.be/L9dtyvOELig)

[Verify that you have an official mod version](https://sha256-islesplus.chrrisk.workers.dev/)

**Server IP:** `skyblockisles.net` *(not affiliated)*

**Mod created by:** `chrrisk & Scrolls`
## Features (Access using `/ip`)
### ⚙️ QOL
- **Custom UI** - custom designed `/ip` menu and HUDs
- **Inventory Search Bar** - filter by name or `#lore` tag (comma for multiple filters), with a built-in calculator
- **Inventory Full Notification** - notify on full inventory until `J` (default keybind)
- **Slot Locking** - press `L` (default keybind) to lock armor/inventory slots
- **Chat Filters** - hide Mana Meteor messages, Guild chat, and/or Player Deaths (never hides player chat)
- **Plushie Finder** - highlights nearest unowned plushie with a waypoint and an adjustable range
- **Waystone Finder** - glows waystones and shows a name tag on the closest one, even when it's too far for the model to load
- **Boss Timers** - HUD panel showing boss timers, with a quick RUN /BOSSARY button in `/ip`
- **Ground Item Alert** - alerts you to items on the ground
- **Auto Party** - save and manage party groups
- **Mod-only Sounds** - silence game audio and hear only mod alerts
### ⛏️ Node Farming
- **Node Radius** - particle ring around your active node
- **Drop Notify** - announces 8× and 16× drops with configurable sound
- **Node Depleted Ping** - alerts when your current node runs out
- **Regen Mode** - pings when your node regenerates (with optional single-ping or ping-until-refarm)
- **Harvest Timer** - displays a colour-coded timer over your node showing when it will deplete (`≈` marks estimates)
- **QTE Tracker** - highlights quick time events and tracks tick skips while farming (woodcutting, fishing, mining, farming) *(beta)*
### 🏚️ Rift
- **Button Finder** - highlights Rift buttons
- **Chest Finder** - highlights Rift chests
- **Grub Machine Finder** - highlights Rift grub machines
- **Mob Finder** - highlights nearby Rift mobs
- **Player Highlight** - highlights nearby players in Rifts
- **Score Calculator** - live rank HUD in Rifts, with Rift Spelunker event support
- **Rift Warning** - on-screen warning in Rifts
- **Custom Finder Colours** - set any hex colour and brightness for every finder
### ⌨️ Hotkeys
- **Keybind Rebinding** - change any keybind right inside `/ip`, including mouse buttons, with conflict warnings
- **Resource Vault** - open with `/rvault` (or keybinded via settings)
- **Backpack & Trash** - quick access via `/bp` and `/trash` (or keybinded via settings)
- **Super Jump** - dash and jump at the same time with one keybind
